WAREHOUSE PICKER — READY-TO-USE PWA

What is included:
- Imports the normal Sage XLSX sales-order export.
- Finds the Sage picking columns automatically.
- Combines duplicate product lines.
- Shows one product at a time.
- Barcode present: camera scan or manual barcode entry.
- Correct barcode = green CORRECT PRODUCT.
- Wrong barcode = red WRONG PRODUCT and picking does not advance.
- Quantity must exactly match the Sage quantity.
- No barcode: product code + full description + quantity, with manual confirmation.
- Works on iPhone and Android as a browser/PWA.

IMPORTANT:
For camera scanning, the app must be opened from a secure HTTPS web address.
The ZIP itself is not an installable iPhone/Android binary. Once this folder is hosted on HTTPS, open it on the phone and choose “Add to Home Screen” (iPhone) or “Install app” (Android).

The app is deliberately designed so your existing Sage Excel export does not need to be redesigned.
